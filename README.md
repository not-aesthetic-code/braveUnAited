# BRAVE UnAIted

Base app for **BRAVE UnAIted** — 8h AI hackathon, 2026-08-28, Butelkownia Warszawa.

This repo is the pre-hackathon skeleton: deployed, working, and empty on purpose.
Nobody should spend hackathon morning configuring anything — see [CHECKLIST.md](./CHECKLIST.md).

**Stack:** Next.js (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui · Vercel

**Live:** deploy URL goes here once the team's first `main` push lands.

## Quick start

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

```bash
pnpm build      # production build, same as Vercel runs
pnpm lint
```

## Adding UI

```bash
pnpm dlx shadcn@latest add <component>
```
