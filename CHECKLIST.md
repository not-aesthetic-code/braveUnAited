# Checklist before start

Everything here is done the evening before, straight from the guidebook page 12.
If it's checked, 9:00 starts with building, not configuring.

## Accounts & access

- [x] GitHub — repo created, team invited via Settings > Collaborators
- [ ] GitHub Desktop installed for anyone not comfortable with a terminal
- [ ] Claude Code (or your agent) installed, logged in, run once
- [x] Vercel — connected to GitHub, auto-deploy on push to `main`
- [ ] Any API keys (Gemini, ElevenLabs, etc.) generated and limits checked
- [ ] Figma / Canva account if you're doing graphics or the pitch deck
- [ ] Ticket QR saved offline on your phone

## Bring

- [ ] Laptop + charger
- [ ] Headphones
- [ ] Phone hotspot as backup (300 people on one Wi-Fi)
- [ ] HDMI / adapter for less common ports
- [ ] Water + snacks
- [ ] Shoes for the after-party — it's part of the agenda

## 30 minutes, the day before

1. **Test deploy.** Push anything to `main`, confirm it goes live on Vercel.
2. **Update everything.** OS, browser, editor — so nothing starts installing at 9:15.
3. **Repo ready to go.** README has the idea and role split. Day starts building at 9:00, not configuring.
